# v0.1 Kapsami

## Foundation v0.1.1

Dahil:

- Rust workspace.
- Layered Core.
- Document Service ve Repository kontrati.
- In-memory repository.
- Platform klasorleri.
- CI omurgasi.
- Ayrintili docs yapisi.

Dahil degil:

- DOCX parser.
- Tauri runtime.
- Rich text editor.
- Cloud hesap.
- Collaboration.

## v0.1.x Writer hedefi

- Yeni belge.
- Dosya ac/kaydet.
- Basit paragraph ve text run modeli.
- Bold, italic, underline.
- Font family ve font size.
- Alignment.
- Undo/redo.
- Autosave/recovery.
- Basit tablo ve resim.
- DOCX import/export minimum uyumluluk profili.
- PDF export.

Kapsam disina cikis ancak roadmap guncellemesi ile yapilir.
