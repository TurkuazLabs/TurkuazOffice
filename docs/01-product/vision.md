# Urun Vizyonu

## Problem

Gunluk ofis kullanicilarinin buyuk bolumu onlarca ileri seviye ozellige ihtiyac duymadan belge yazmak, tablo duzenlemek, dosya acmak, PDF almak ve dosyasini guvenle saklamak ister.

## Cozum

Turkuaz Office sade UI, hizli acilis, dusuk kaynak kullanimi ve moduler mimari ile temel ofis islerini hedefler.

## Urun ilkeleri

1. Gunluk isler birinci onceliktir.
2. Basitlik ozellik eksikligi degil bilincli kapsam yonetimidir.
3. Belge verisi UI teknolojisine baglanmaz.
4. Desktop, Web ve Mobile ayni document semantics uzerinde calisir.
5. Local-first kullanici cloud hesabi olmadan da calisabilir.
6. Cloud ozellikleri eklendiginde local dosya akisini bozmaz.
7. Plugin API cekirdegi kontrolsuz sekilde delmez.
8. Dosya uyumlulugu tahminle degil fixture ve round-trip testleriyle olculur.

## Basari olcutleri

Ilk basari; Windows ve Linux'ta stabil Writer kullanimi, temel DOCX import/export, PDF cikti, autosave/recovery ve veri kaybi olmadan gunluk kullanimdir.
